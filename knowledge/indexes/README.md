# Knowledge Indexes

This folder is the first knowledge-base orientation entry point for future sessions.

## Read First

1. `README.md` for the user-facing project overview.
2. `AGENTS.md` for the agent operating contract.
3. `knowledge/indexes/README.md` for the current knowledge-base map.

## Folder Roles

- `knowledge/raw/` holds source evidence. New converted markdown sources and manual notes land in `knowledge/raw/inbox/`.
- `knowledge/sources/` holds one derived source-summary file per processed raw source.
- `knowledge/wiki/` holds compiled modernist cooking articles, organized into `concepts/`, `techniques/`, `ingredients/`, `equipment/`, `recipes/`, and `safety/`.
- `knowledge/indexes/` holds navigation, traceability, backlink, and open-question indexes.
- `knowledge/outputs/` holds exploratory answers, comparisons, briefs, and recipe-development notes.
- `knowledge/health/` holds audits and improvement reports, with reports in `knowledge/health/reports/`.
